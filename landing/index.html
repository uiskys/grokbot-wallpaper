Install in a minute.

Download, then three steps.

Windows

Windows 10 or 11

Download .zip For Lively Wallpaper (free)
  1. Install Lively Wallpaper. It is free on the Microsoft Store.
  2. Drag the zip into Lively. No need to unzip it.
  3. Set it as your wallpaper. Click Grok Bot in Lively’s library.

Mac

macOS 13 or later

Download .dmg Apple silicon and Intel If Chrome blocks it, download with Safari or choose Keep.
  1. Open the .dmg. It is in your Downloads.
  2. Drag Grok Bot Wallpaper to Applications.
  3. First launch: macOS says it can’t check the app. Click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway. The app isn’t notarized yet, so this happens once.On macOS 14 or earlier: right-click the app, then Open.

Show your bots. Have a bots channel? Paste it into the wallpaper’s settings and your bots appear beside Grok Bot as live cards. In Lively: Customise → Your bots channel. On a Mac: the 👀 menu-bar icon → Bots channel….

For AI agents

Someone gave you this page and asked you to set it up? Here is what to do.

  1. Grok Bot: show the user what the setup prompt below does and ask them to confirm once, then run it step by step. It adds one status line to each bot’s instructions, posts only the bots’ names, statuses, teams, looks, routines, chat links and usage percent to a private channel, and ends with the user’s link. That link works like a password: give it only to the user.
  2. An agent on the user’s computer (Claude Code and others). Windows 10 or 11: the user installs Lively Wallpaper (free, Microsoft Store); download https://github.com/Bodila51/grokbot-wallpaper/releases/download/windows-v1.0/grokbot-wallpaper-windows.zip and ask the user to drag it into Lively (Lively can’t import it from the command line). macOS 13 or later: download https://github.com/Bodila51/grokbot-wallpaper/releases/latest/download/GrokBotWallpaper.dmg, copy Grok Bot Wallpaper.app to /Applications and open it; the user approves it once in System Settings → Privacy & Security → Open Anyway.
  3. Bots on the wallpaper: the user pastes the link from Grok Bot into Lively (Customise → Your bots channel) or, on a Mac, into the 👀 menu-bar icon → Bots channel….
